# Banking Application

## Project Description
This project is a Banking Application designed to manage banking services and customer accounts digitally.

## Features
- Customer Registration
- Customer Login
- Check Account Balance
- Money Transfer
- Transaction History
- Account Management
- Track Complaint Status
- FAQs
